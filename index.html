MTB peer deposit rate monitoring · Offline desktop application

Create ALCO PowerPoints without a website.

Use the Windows app to attach bank PDF rate sheets, review extracted figures, and generate editable presentations using the original FDR and DPS templates. No login, website access, or internet connection is needed once the app is downloaded.

Bank-by-bank PDF upload

Every bank has its own Upload PDF button inside the app. Files cannot accidentally be assigned to a different bank.

Six customizable peer slots are available without altering the original slide layouts.

How to use it

  • Download and unzip the Windows package.
  • Run MTB_ALCO_Tool.exe from the extracted folder.
  • Click Upload PDF beside each bank, then Extract Rates.
  • Correct unmatched figures if necessary, then Generate Original PowerPoints.

Included tools

  • Original-format, editable FDR and DPS PowerPoint reports
  • Change or remove peer banks, with comparable-product mappings
  • Screenshot-to-searchable-PDF and text-to-extractable-PDF
  • PDF-only data sources; missing rates shown as –, Proposed Rate blank
